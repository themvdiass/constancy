# Constancy

Aplicação React preparada para publicação no GitHub Pages.

## Desenvolvimento

```sh
npm install
npm start
```

## Publicação

```sh
npm run deploy
```

A configuração de publicação fica em `package.json` (`homepage`, `predeploy` e `deploy`). Os redirecionamentos de Single Page App do GitHub Pages estão em `public/index.html` e `public/404.html`.
